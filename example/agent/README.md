# Example personal Pi config

Copy these files to `~/.pi/agent/` and edit them for the machine.

- `settings.json` — Pi defaults
- `keybindings.json` — Custom keybindings
- `blacklist.json` — Path blacklist used by the path-blacklist extension
- `mcp.example.json` — Template for MCP servers; copy to `mcp.json` and fill in secrets
